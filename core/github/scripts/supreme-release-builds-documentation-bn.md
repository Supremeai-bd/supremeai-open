# 📖 রিলিজ বিল্ড ওয়ার্কফ্লো (`supreme-release-builds.yml`)

এই ডকুমেন্টটি আমাদের `supreme-release-builds.yml` ওয়ার্কফ্লোর কার্যকারিতা, বিভিন্ন ধাপ এবং এর পেছনের মূল ধারণাগুলো ব্যাখ্যা করে। এই পাইপলাইনটি আমাদের সফটওয়্যারের চূড়ান্ত রিলিজ প্যাকেজগুলো (যেমন: APK, EXE) স্বয়ংক্রিয়ভাবে তৈরি করার জন্য ব্যবহৃত হয়।

---

## 🎯 মূল উদ্দেশ্য: মাল্টি-প্ল্যাটফর্ম রিলিজ তৈরি

এই ওয়ার্কফ্লোর প্রধান লক্ষ্য হলো একটি কেন্দ্রীয় এবং স্বয়ংক্রিয় প্রক্রিয়ার মাধ্যমে বিভিন্ন প্ল্যাটফর্মের জন্য অ্যাপ্লিকেশন বিল্ড তৈরি করা। এটি নিশ্চিত করে যে প্রতিটি রিলিজ একই সোর্স কোড থেকে তৈরি হয়েছে এবং বিল্ড প্রক্রিয়াটি সামঞ্জস্যপূর্ণ ও নির্ভরযোগ্য।

এর মূল কাজগুলো হলো:
-   অ্যান্ড্রয়েড অ্যাপের জন্য **APK** ফাইল তৈরি করা।
-   উইন্ডোজের জন্য **EXE** ইনস্টলার তৈরি করা।
-   ভিজ্যুয়াল স্টুডিও কোডের জন্য **VSIX** এক্সটেনশন প্যাকেজ তৈরি করা।

---

## 🚀 ওয়ার্কফ্লো ট্রিগার

এই ওয়ার্কফ্লোটি সাধারণত নিম্নলিখিত ঘটনাগুলোর উপর ভিত্তি করে চালু হয়:

1.  **`workflow_dispatch` (ম্যানুয়াল):**
    -   GitHub Actions UI থেকে যেকোনো নির্দিষ্ট ব্রাঞ্চ বা ট্যাগ সিলেক্ট করে এটি ম্যানুয়ালি চালানো যায়। এটি নতুন রিলিজ তৈরির প্রধান উপায়।

2.  **`release` (স্বয়ংক্রিয়):**
    -   **শর্ত:** যখন একটি নতুন GitHub Release তৈরি বা পাবলিশ করা হয়।
    -   **কাজ:** এটি স্বয়ংক্রিয়ভাবে ট্রিগার হয়ে সেই রিলিজের সাথে যুক্ত ট্যাগ থেকে কোড নিয়ে বিল্ড শুরু করে।

---

## 🛠️ প্রধান জব এবং তাদের কার্যকারিতা

এই ওয়ার্কফ্লোটি একটি **ম্যাট্রিক্স স্ট্র্যাটেজি (Matrix Strategy)** ব্যবহার করে, যার মাধ্যমে একই সাথে একাধিক অপারেটিং সিস্টেমের জন্য বিল্ড চালানো যায়।

-   **জব:** `build-releases`
-   **ম্যাট্রিক্স:**
    -   `os`: `[ubuntu-latest, windows-latest, macos-latest]`
    -   `target`: `[android, windows, vscode]`

### বিল্ড ধাপসমূহ

প্রতিটি ম্যাট্রিক্স জব নিম্নলিখিত ধাপগুলো অনুসরণ করে:

1.  **কোড চেকআউট:** নির্দিষ্ট ব্রাঞ্চ বা ট্যাগ থেকে সোর্স কোড ডাউনলোড করে।

2.  **পরিবেশ সেটআপ:**
    -   Node.js এবং pnpm সেটআপ করা হয়।
    -   `pnpm install --frozen-lockfile` কমান্ডের মাধ্যমে সমস্ত নির্ভরতা (dependencies) ইনস্টল করা হয়।

3.  **প্ল্যাটফর্ম-নির্দিষ্ট বিল্ড:**
    -   **অ্যান্ড্রয়েড (Android APK):**
        -   `pnpm turbo run build --filter=mobile` চালিয়ে মোবাইল অ্যাপ বিল্ড করা হয়।
        -   ফলাফল হিসেবে একটি APK ফাইল তৈরি হয়।
    -   **উইন্ডোজ (Windows EXE):**
        -   `pnpm turbo run build --filter=desktop` চালিয়ে ডেস্কটপ অ্যাপ বিল্ড করা হয়।
        -   ফলাফল হিসেবে একটি EXE ইনস্টলার তৈরি হয়।
    -   **ভিএস কোড (VS Code VSIX):**
        -   `pnpm turbo run build --filter=vscode-extension` চালিয়ে VS Code এক্সটেনশন বিল্ড করা হয়।
        -   ফলাফল হিসেবে একটি VSIX ফাইল তৈরি হয়।

4.  **আর্টিফ্যাক্ট আপলোড:**
    -   প্রতিটি সফল বিল্ডের পর, তৈরি হওয়া ফাইলটি (`.apk`, `.exe`, `.vsix`) একটি আর্টিফ্যাক্ট হিসেবে আপলোড করা হয়।
    -   পরবর্তীতে, এই আর্টিফ্যাক্টগুলো GitHub Release-এর সাথে যুক্ত করে দেওয়া হয়, যাতে ব্যবহারকারীরা সহজেই ডাউনলোড করতে পারেন।
