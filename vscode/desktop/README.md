# SupremeAI Desktop Application

Native Windows, macOS, and Linux desktop workstation application for SupremeAI.

## Architecture & Responsibilities
- System tray status and instant global keyboard shortcuts (`Ctrl+Alt+S` / `Cmd+Alt+S`).
- Local agent runtime management and IPC bridge.
- Standalone multi-model workspace and autonomous workflow supervisor.
- Released via GitHub Releases as native installer binaries (`.exe`, `.dmg`, `.AppImage`).
