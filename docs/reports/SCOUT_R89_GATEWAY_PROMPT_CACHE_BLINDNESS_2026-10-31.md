## The finding in one paragraph

The gateway (`gateway/`) is the public chat relay for SupremeAI's guest traffic (`$0 Cost / 24/7` is the design goal stated verbatim in `gateway/SYSTEM_CHAT_AND_DEPLOYMENT_ARCHITECTURE.md`), and provider-side prompt caching is the single largest known cost lever on that plane — every provider family the auto chain rides except the direct-Anthropic compat leg now bills cached-prefix input tokens at 50–98% off (live-verified 2026-10-31, evidence table below) — yet the relay plane is **cache-blind in both directions**: outbound it constructs the minimal body `{model, messages, stream}` and never sends any cache opt-in marker (`gateway/provider_chain.py` L167–171), and inbound it echoes provider `usage` verbatim but extracts, counts, or exports nothing about cached tokens (zero `cached_tokens` mentions repo-wide outside the core satellite; `gateway/metrics_exporter.py` exports only HTTP request/latency families). The federation already holds the landed precedent — the core satellite's **PLAN-001: Anthropic prompt caching (2026-09-17)** in `core/llm/providers/cloud_adapter.py` marks the cacheable system prefix with `cache_control: {"type": "ephemeral"}` and surfaces cache telemetry — the gateway plane simply never adopted it. No outage exists today; the exposure is a silent, measurable overspend on every repeated-prefix request the guest chat and loop dispatches send through the chain.

## Why this matters for SupremeAI specifically

The gateway is the federation's front door for guest chat, and the architecture doc's own headline is `$0 Cost / 24/7 High-Availability` with multi-account free-tier key pools (`GROQ_API_KEYS`-class comma pools in `provider_chain.py`). Every 429/401 rotation the pools perform is a free-tier budget under pressure; a 50–95% input-price reduction on the stable system-prefix + conversation-history portion of each request directly extends every pool's daily budget and defers the first paid upgrade. The workloads are the ideal cache shape — multi-turn guest chat resends the full history every turn, and loop dispatches repeat near-identical dispatch-prompt prefixes — yet today the system cannot even measure its cache-hit rate (I3), so the lever is not merely unused, it is unobservable. This is the same fail-silent family the board has root-caused elsewhere (R88's interceptor-behind-the-vendor-plane; U2 unseen-plane blindness): here the unseen plane is the cost plane.
