## The finding in one paragraph

`gateway/routing_policy.json` (schema `gateway-routing/1`) routes the `auto` chain through nine legs across seven providers. Live vendor-plane verification on 2026-10-31 (four vendor documentation planes + one zero-credential public API probe) shows **three legs stand on deprecation/restricted/preview ground and a fourth is one generation behind the vendor's current recommendation**, while `gateway/model_horizon.json` (version 2026-10-24, whose self-declared purpose is "to intercept drift and flag retired models") **still marks one of the deprecated models `active` — ten days after the vendor's deprecation notice — and carries no entry at all for the chain's terminal fallback**. No outage exists today; the exposure is a dated, verifiable time bomb plus a monitoring blind spot in the exact file built to prevent this class.

## Why this matters for SupremeAI specifically

The `auto` chain is the gateway's default routing path (`"default_chain": "auto"`). The chain's design premise is ordered failover; the value of the ladder collapses silently if late legs die on a vendor calendar the repo does not track. E1 is the sharpest instance: when `gpt-4o-mini` shuts down on 2027-01-14, the chain's terminal fallback begins returning provider errors on every request that falls through eight legs — and nothing in-tree flags it today, because the horizon interceptor's vocabulary (training-cutoff drift) does not include vendor-deprecation drift (E6). This is the same fail-silent family the board has repeatedly root-caused elsewhere (R84 lease-plane fail-silence; U2 unseen-plane blindness) — here it is a dated, verifiable instance with a 75-day fuse.
