## Why this matters for SupremeAI specifically

The federation's loop already routes CI incidents to agents, but the dedup burden sits on every filer's discipline (anti-stampede U5) instead of in the mechanism — and today proved the cost: six same-incident receipts in seven minutes, several of them overlapping-lane re-triages that the receipt-coverage demotion had to filter AFTER the spend. `gh aw`'s CI Doctor inverts that: one issue per failure subject, update-in-place on recurrence, machine audit trail — plus it runs entirely inside GitHub Actions with declarative permissions, so the single-write-gateway doctrine is testable per-workflow (`safe-outputs: create-issue` only) rather than assumed. The repo's AGENTS.md is already the source-controlled constitution the platform's custom-agent plane expects (R23-VI lane), so the on-ramp is a workflow file, not a migration.
