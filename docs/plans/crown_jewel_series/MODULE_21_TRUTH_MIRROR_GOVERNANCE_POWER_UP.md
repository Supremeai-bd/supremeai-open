# Module 21 — Truth-Mirror Governance Script Power-Up (সত্য-আয়না গভর্নেন্স)

## বাংলা সারসংক্ষেপ

এই চক্র অন্যরকম — অঙ্গ-অডিট নয়, **আত্ম-উপকারী টুল-নকশা**: সিরিজের ৮ চক্রে হাতে-আবিষ্কৃত **১৫+ false-assurance পৃষ্ঠ** (জাল-KPI, জাল-'sent', জাল-OTP, optimistic-verification, কখনো-অনারম্ভিত task, mock-key-লিটারেল...) একটি **rules-as-data সনাক্তকারীর বীজ-কর্পাস**। মূল-শ্রেণি-সিদ্ধান্ত প্রমাণ-জোড় দিয়ে আঁকা: `fake_store.py` (সৎ — লেবেলযুক্ত টেস্ট-ফেক) বনাম `webhooks_ai` (অসৎ — production-জাল-'sent')। শিল্প-গবেষণা নাম দিয়েছে আমাদের পুরনো-বন্ধুকে: **exclusion ratchet** (arXiv 2026-08) — আমাদের baseline-N মতবাদের সরকারি-সমতুল্য; আর **over-mocked agents** (arXiv 2026-01) প্রমাণ করে AI-যুগে ফেব্রিকেশন শিল্প-ব্যাধি — আমাদের আয়না তাই ভবিষ্যৎ-নিরাপদ। নকশা: stdlib-CLI, নিয়ম-YAML-এ, সংকেত-ত্রি-মাত্রিক (পথ+স্বীকারোক্তি+কলার), warn-only-প্রথম, anti-gaming-সাক্ষ্য-মার্কার। **এই ডক কোনো কোড তৈরি করে না** — ফাউন্ডার-গেটের পরে আলাদা execution-প্ল্যান।

| **সরাসরি CI-গেট-শুরু** | Module 10/11 মতবাদ: warn-only→zero-false-positive-প্রমাণ→গেট; ব্যতিক্রম ছাড়া গেট = বিশ্বাস-ভাঙা |
| **knip-বিস্তার-নির্ভরতা** | knip আমদানি-গ্রাফ-ভিত্তিক — আচরণ-ফেব্রিকেশন (জাল-KPI, জাল-'sent') তার দৃষ্টির বাইরে; census-প্রমাণ |

### ১.৩ প্রতিযোগী-তুলনার অন্তর্দৃষ্টি (ভিন্নভাবে ভাবা)

শিল্পের নিরাপত্তা/গুণ-টুল বাহ্যিক-কর্পাসে শেখে (CVE-ডেটাসেট, বাগ-রেপো)। আমাদের ভিন্ন-সম্পদ: **নিজের হাতে-লেখা নির্ভুল-আবিষ্কার-কর্পাস** — ৮ চক্রে প্রতিটি আবিষ্কারের file:line প্রমাণ-নথিভুক্ত। "নিজের ব্যর্থতা-নথিই শ্রেষ্ঠ নিয়ম-বই" — বাইরের ডেটাসেট কেনা/শেখার ব্যয়-ছাড়াই zero-false-positive-সক্ষম বীজ। আর টুলের সীমানা স্বীকার-পূর্ব: আয়না দেখায়, রায় দেয় না — রায় ফাউন্ডারের (V6/V7-চক্রের সঙ্গী-ইনপুট)।

## Part 2 — Six-Field Analysis

### ২.১ কী আছে

- **প্রমাণিত-প্যাটার্ন**: lint_plans.py-র শ্রেণি-কাঠামো (CLI + শ্রেণি-সন্ধান + EVIDENCE_MARKERS + রিপোর্ট) — কোড-স্তরে পুনঃপ্রয়োগযোগ্য
- **বীজ-কর্পাস**: সিরিজের ১৫+ আবিষ্কার, প্রতিটি file:line-প্রমাণিত — নিয়ম-বীজ প্রস্তুত
- **শ্রেণি-প্রমাণ-জোড়**: fake_store (সৎ) / webhooks_ai (অসৎ) — শ্রেণিবিন্যাসের সোনালি-নমুনা
- **CI-সংস্কৃতি**: report-only-স্লট ইতোমধ্যে বিদ্যমান (ci.yml/audit-release.yml); V6/V7-হাত-চক্র চলমান

### ২.২ কী নেই

- **কোড-স্তর সনাক্তকারী** — আচরণ-ফেব্রিকেশন (জাল-সাফল্য-ফেরত, কখনো-অনারম্ভিত-task, unreachable-mock-branch) কোনো বর্তমান টুল দেখে না
- **সৎ/অসৎ শ্রেণিবিন্যাস** — নাম-grep দুই-দিকেই ভুল (১৩২ frontend-ফাইলের অধিকাংশ বৈধ-টেস্ট; জাল-KPI মক-ফাইলে নয়)
- **baseline ব্যতিক্রম-শৃঙ্খলা** — কোড-স্তরে কিছুই নেই
- **anti-gaming** — সংকেত-সাক্ষ্য-বাধ্যতা শূন্য

### ২.৩ কী করতে হবে

নকশা-প্রস্তাব ৮টি (সব founder-gated; এই ডক কোনো কোড তৈরি করে না):

- **P-A**: truth_mirror_rules.yml — নিয়ম=id+signal+evidence-marker+severity+exclusion-path; বীজ: সিরিজ-কর্পাসের ১৫+ (প্রতিটির সূত্র-সহ)
- **P-B**: শ্রেণিবিন্যাস-প্রথম — ত্রি-মাত্রিক সংকেত: (১) পথ-প্রেক্ষাপট (tests/scripts = সৎ-অঞ্চল), (২) docstring-স্বীকারোক্তি (fake_store-ঘরানা = সৎ), (৩) কলার-গণনা (production-পথে জাল-সাফল্য-ফেরত = অসৎ)
- **P-C**: সংকেত-ট্যাক্সোনমি — fabricated-return (বিনা-কাজে success/sent), fabricated-literal (KPI/মেট্রিক লিটারেল), unreachable-mock-branch, never-started-task, unfed-store, fake-fallback-values
- **P-D**: exclusion-ratchet বেসলাইন — N→pass/N+1→fail; ব্যতিক্রম-রেকর্ডে last-reviewed; ৯০-দিন-পুনঃপরীক্ষা-নোট
- **P-E**: warn-only CLI → zero-false-positive প্রমাণ (প্রতিটি বীজ-নিয়ম প্রমাণ-ফাইলে ফায়ার + সৎ-সমতুল্যে non-ফায়ার) → তবেই founder-gated CI-স্লট-প্রস্তাব
- **P-F**: আউটপুট — markdown রিপোর্ট (প্রমাণ-সূত্রসহ) + exit-কোড নীতি; lint_plans-পরিবার-শৈলী
- **P-G**: পরিমাপ — মাসিক-ফেব্রিকেশন-গণনা-প্রবণতা (লক্ষ্য →০); V6/V7-চক্র-ইনপুট-রূপ
- **P-H**: anti-gaming — প্রতিটি সংকেতে সাক্ষ্য-মার্কার-বাধ্যতামূলক (backticked-path/commit/PR); মার্কার-বিহীন সংকেত অবৈধ
- **P-I**: জিরো-বাইপাস ইনফ্যারেন্স গভর্ন্যান্স ও লিভিং প্ল্যান রিকনসিলিয়েশন (Zero-Bypass Inference Governance & Living Plan Audit):
  - **Zero-Bypass রুল এনফোর্সমেন্ট:** ট্রুথ-মিরর নিয়মে AST-স্ক্যানার যুক্ত করা, যা কোনো নতুন কোডে `backend/services/llm_gateway.py` ব্যতীত সরাসরি LLM কল বা কাঁচা HTTP রিকোয়েস্ট শনাক্ত হলে তৎক্ষণাৎ ফ্ল্যাগ তুলবে।
  - **লিভিং প্ল্যান সত্য-যাচাই:** `docs/plans/` ডিরেক্টরির প্রতিটি আর্কিটেকচার প্ল্যান কোডবেসের বাস্তব ফাংশনের সাথে সিঙ্ক আছে কিনা এবং কোনো অসত্য বা আনভেরিফায়েড SLA দাবি আছে কিনা তা নিয়মিত যাচাই করবে।

### ২.৪ কীভাবে করব

Gate 2-পরবর্তী আলাদা ছোট execution-প্ল্যান; নির্মাণ-ক্রম P-A→P-B→P-C→P-D→P-F→P-H→P-I→P-E→P-G (প্রমাণ-স্তর P-E সবার ফল-যাচাই); stdlib-শুধু; YamlSafeLoader-নিরাপদ; প্রতিটি নিয়ম-যোগ = এক-প্রমাণ-পাথ + সৎ-নন-ফায়ার-পাথ — zero-false-positive-সংস্কৃতি lint_plans-চেক-লজিকের সরাসরি-উত্তরাধিকার

### ২.৫ বেনিফিট

- সিরিজের মূল্যবান আবিষ্কার ভুলে-যাওয়া-নয় — টুলে অমর; নতুন-ফেব্রিকেশন PR-সময়েই দৃশ্যমান (warn)
- জিরো-বাইপাস বাউন্ডারি স্বয়ংক্রিয়ভাবে পাহারা দেওয়া হবে — প্ল্যাটফর্মের কোনো মডিউলে আন-মিটারড বা আন-মনিটর্ড মডেল কল সম্ভব নয়।
- লিভিং প্ল্যান কর্পাস সর্বদা কোডবেস বাস্তবতার সাথে ১০০% বিশ্বস্ত ও নির্ভুল থাকবে।
- V6/V7-হাত-চক্রের শ্রম-হ্রাস (আয়না-প্রি-স্ক্যান)
- AI-যুগের শিল্প-ব্যাধির (over-mocking) স্থানীয়-প্রতিষেধক
- zero-false-positive-সংস্কৃতির তৃতীয়-স্তম্ভ (lint_plans → duplicate-detector → truth-mirror)
- ফাউন্ডার-রায়-কেন্দ্রিক থাকায় শাসন-দর্শন অটুট

### ২.৬ ক্ষতি/ঝুঁকি

- ব্যতিক্রম-র‍্যাচেট-অপব্যবহার (সবকিছু exclude) → exclusion-গণনা-সীমা + last-reviewed-নথি + P-H-সাক্ষ্য
- সংকেত-অতি-সংবেদনশীলতা → প্রমাণ-পাথ/নন-ফায়ার-পাথ-জোড়-বাধ্য প্রতি-নিয়মে
- টুল-নিজে-বিস্মৃত (ডকুমেন্টেড-কিন্তু-অচালিত অঙ্গের পুনরাবৃত্তি!) → P-G-পরিমাপ + V6-চক্র-সংযোগ — নিজের সিরিজ-পাঠের প্রয়োগ
- YAML-ব্যবহারকারী-ভুল → SafeLoader+last-known-good-অভ্যাস
