# Spec Kit Pilot (R25 → #1710) — Field Comparison: Spec Kit vs. PR Blueprint / Bridge Contract

> **Task ID:** `bridge-20261029-speckit-pilot-1710` (step 3 of 3)
> **Question:** which Spec Kit fields duplicate what the PR blueprint and bridge intake
> already enforce, and which are worth adopting?
> **Baseline documents:** AGENTS.md invariant 4 (3-Tier Verify: Reflection → Smoke →
> Tests; PRs carry `Closes #N` + `## Reflection Evidence (why + alternatives_rejected)`),
> the bridge submission payload (taskId, summary, scopePaths, testsEvidence, rollbackPath,
> agentIdentity, reflectionWhy, alternativesRejected), and the intake contract
> (diffCaps / secretScanFamilies / protectedPaths with three-way verdicts — mapped for the
> ACS lane in docs/reports/ACS_EVAL_2026-10-29.md).

## Comparison table

| Spec Kit field | Existing counterpart | Finding | Verdict |
|---|---|---|---|
| assessed cause (bug-fix ext.) | PR Reflection "why" | Same intent: mechanism-level root cause before fix | Duplicate — keep blueprint wording |
| scoped fix (bug-fix ext.) | smallest-safe-slice doctrine + scopePaths | Same intent: bounded diff, declared boundaries | Duplicate |
| recorded verification (bug-fix ext.) | 3-Tier Verify + testsEvidence | Blueprint is **stronger**: three named tiers beats one "recorded" step | Duplicate — no new field |

| kill criteria (idea ext.) | **none** | Genuine gap: feature WOs can drift indefinitely with no pre-agreed stop condition; the idea-assessment pilot (#1520/#1523 instantiations) shows the field earns its keep immediately | **ADOPT** as an optional template field on feature RFCs |
| convergence signal (idea ext.) | bridge stamp plane (landed/rejected/admin-review) + WO lifecycle labels | Overlaps: convergence is currently stamped post-hoc; the Spec Kit field states it up-front — marginally useful, fold into the kill-criteria adopt | Fold into ADOPT above |
| `/speckit-constitution` | AGENTS.md (landed SSOT) | **Conflict by default**: the constitution is landed, never regenerated by a foreign tool (R25 conflict-by-default rule) | REJECT |

## Adopted-slice recommendation (doc-only, honored by this pilot)

1. **Adopt:** kill criteria + convergence signal as two optional lines on feature-RFC
   templates (the Instantiation docs demonstrate the shape; no code, no schema).
2. **Reject:** everything the blueprint or intake already enforces — adding a parallel
   field would split the record of truth across two formats.
3. **Never adopt:** constitution regeneration or the specify toolchain (Single Door).

## Pilot closure

R25's verdict was `quarantine_eval` — borrow process artifacts only. This three-doc pilot
executes the borrow-and-measure step: one template family instantiated forward (3 WOs)
and retrospectively (#1679), one comparison page with per-field verdicts. Measured
result: exactly one field family (kill criteria / convergence signal) survives the
duplicate test. That is the whole adoption surface; anything further would be process
growth without evidence.
